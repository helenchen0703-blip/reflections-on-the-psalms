## 关于本书

- **书名**: 诗篇撷思 (Reflections on the Psalms)
- **作者**: C.S. Lewis（鲁益师/路益师）
- **译者**: 曾珍珍
- **出版**: 雅歌出版社, 1991 年初版（英文原著 1958 年）
- **内容**: 一位基督徒文学批评家分享他初读《诗篇》时的困惑、疑虑与领悟
