# 决策规则速查 — 诗篇撷思

| 能力 | 一句话规则 |
|---|---|
| 按诗歌体裁读诗篇 | 指出共同的渴慕；比较旱地/干土与雨/水；不由两个说法制造两套恩赐。 |
| 解释审判的不同位置 | 从伸冤诉求解释喜乐，不断言所有犹太人都不惧怕神。 |
| 把具体是非与人格评价分开 | 先确认返还问题；不因乙乖而改归属；自愿赠与另谈；不替甲脾气开脱。 |
| 检查自己是否公平地争论 | 找出两项可核不公；不读心他人；给一项可执行纠正。 |
| 面对咒诅与义愤而不美化报复 | 承认暴力内容；不作神圣授权；理解受伤不等于赞同报复；不逼迫和解。 |
| 检查手段是否取代目的 | 区分媒介与目的；用取消讨论这一证据，而非否定排版本身；提出恢复目的的调整。 |
| 理解律法为何“比蜜甘甜” | 否定规则数量与道德优越性的推断；说明欣赏秩序而非仅自满。 |
| 在社交中避免附和与自义 | 不补充隐私、不陪笑认可；给具体回应；不用身份标签判人；若环境持续有害可离开。 |
| 把赞美作为欣赏的真实表达 | 立足给定的真实细节；不凭空夸大、不索回报、不强迫神学赞美情绪。 |
| 区分原义、第二义与个人联想 | 保留婚礼第一义；指出传统或神学前提需证据；区别个人联想；不将相似直接判预言。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
