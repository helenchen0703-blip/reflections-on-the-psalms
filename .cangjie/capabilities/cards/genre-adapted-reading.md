# 体裁适配阅读法

## R — 原文 (Reading)

> 诗篇必须当作诗歌读……对仗是希伯来诗歌的格律，"同中有异、异中有同、相映成趣"，是翻译后仍不失的格律。不可当作教义论文或预言清单来读。
>
> — C.S. Lewis，《诗篇撷思》第 1 章 导论

---

## I — 方法论骨架 (Interpretation)

面对任何文本，第一步不是问"它说了什么"，而是问"它是什么体裁"。

不同体裁有不同的阅读规则：诗歌要按意象累积来读，教义要按逻辑推演来读，叙事要按情节发展来读。用错了规则，不是读不懂而是读偏——把诗歌当教义，会读到矛盾；把叙事当律法，会读到荒谬。

希伯来诗歌的核心格律是对仗（parallelism）：第二行用不同措辞重述第一行的意思，不是对立也不是递进，而是"同中有异"。这个格律在翻译后仍然有效——换词不换韵，重述即呼应。

因此读诗歌时，注意力放在意象的累积与回响上，而非逐行提取命题。一首诗的意义在整体意境里，不在单句字面里。

## A1 — 应用示例 (Application Example)

### 示例 1: 诗篇第 29 篇的对仗结构

- **类型与来源**: 合成演练（基于原书第 1 章方法论规则设计，非作者亲历叙述）
- **问题/输入**: 诗篇 29:3–4："耶和华的声音发在水上。荣耀的神打雷，耶和华打雷在大水之上。耶和华的声音大有能力。耶和华的声音满有威严。"
- **方法论的使用**:
  1. 判定体裁：诗歌（非教义论文、非气象记录）
  2. 识别格律：对仗——每两行一组，第二行用不同措辞重述"神的声音"的威荣
  3. 按规则读：不提取"雷=神的声音=教义命题"，而是感受"水上→打雷→大能→威严"意象的累积与回响
  4. 注意：两组对仗不是对立（水 vs 威严）也不是递进，而是同一主题的不同侧面相映
- **结论**: 这首诗的意义不在逐节教义要点，而在于通过反复的意象叠加，让读者沉浸于"神声音之威荣"的体验中
- **结果**: 合成演练结论——按此法读后，不会困惑"为什么神要打雷"（教义式问题），而是感受到诗歌传达的敬畏感

### 示例 2: 把诗篇当教义清单读的典型错误

- **类型与来源**: 原书转述（第 1 章导论，作者对初读者误读的描述）
- **问题/输入**: 同一首诗中同时出现自义（"我未曾偏离你的律法"）和认罪（"求你赦免我隐而未现的过错"）
- **方法论的使用**: 若当教义读→矛盾（既说自己无罪又说自己有罪）；若当诗歌读→两种声音是诗人在不同情绪下对同一信仰关系的表达，意象叠加而非逻辑矛盾
- **结论**: 体裁误判导致读到矛盾
- **结果**: 作者指出这是初读诗篇时最常见的困惑源

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 读一首诗篇（或任何诗歌体经文）时感到矛盾、困惑或抵触——很可能是因为按教义而非诗歌来读了
2. 用户想"从诗篇中提取教义要点"，逐节做笔记，但越读越混乱
3. 用户讨论某段经文"矛盾"或"前后不一致"，但实际上是诗歌对仗结构造成的错觉
4. 用户翻译或分析希伯来诗歌，需要理解对仗格律的运作方式

### 语言信号 (用户的话里出现这些就应激活)

- "诗篇第 X 篇前后矛盾"
- "这段经文自相矛盾"
- "怎么从诗篇里提取教义"
- "对仗是什么 / parallelism"
- "这首诗的每一节是什么意思"
- "how to read Psalms as poetry"

### 与相邻 skill 的区分

- 与 `imprecation-three-step` 的区别: 本 skill 处理的是**怎么读**（体裁规则），后者处理的是**读到反感内容后怎么接纳**（情绪处理）。本 skill 是前置步骤——先判体裁再处理内容。
- 与 `elevated-literature-reading` 的区别: 本 skill 处理诗歌体裁的通用阅读规则（适用一切诗歌），后者处理被赋予宗教权威的文学的特殊阅读姿态（旧约圣经的"提昇"性质）。

## E — 可执行步骤 (Execution)

**必需输入**: 待读文本（或其片段）、文本的体裁信息（若不确定，第一步即判定）
**交付物与完成标准**: 体裁判定结论 + 该体裁的阅读策略 + 避免误读的边界提示

当 skill 被激活后, agent 应按以下步骤执行:

1. **判定文本体裁**
   - 检查特征：是否有对仗结构（诗歌）、情节发展（叙事）、条文格式（律法）、格言式短句（智慧）、启示意象（预言）
   - 完成标准: 明确说出"这是 X 体裁"，并给出判断依据（至少 1 个结构特征）

2. **识别该体裁的格律/结构规则**
   - 诗歌→找对仗：第二行是否用不同措辞重述第一行？
   - 叙事→找情节弧线
   - 律法→找条件句结构
   - 完成标准: 说出该体裁的阅读规则是什么
   - 判停条件: 若文本是混合体裁（如叙事中嵌入诗歌），需分别处理

3. **按规则而非教义提取意义**
   - 诗歌：关注意象的累积与回响，而非逐字命题化
   - 不把对仗的两行当对立或递进的命题
   - 完成标准: 能说出"这首诗/这段文字的整体意境是什么"，而非"第一行说 X、第二行说 Y"

4. **输出阅读策略**
   - 列出该体裁适配的读法要点
   - 列出常见的误读风险（如把诗歌当教义清单读→读到矛盾）
   - 完成标准: 用户拿到后能直接按策略读该文本

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 文本不是诗歌体裁时（叙事、律法、智慧文学各有自己的阅读规则，本 skill 的核心是对仗格律，不通用）
- 用户只想了解文本的字面含义或历史背景时（这是注释学任务，不是体裁适配任务）
- 用户已在正确阅读但仍对内容有情绪抵触时（此时应转 `imprecation-three-step` 或 `praise-essence-reframe`）

### 作者在书中警告的失败模式

- **把诗篇当教义清单读 (ce05)**：把诗歌意象逐字逐句提取为命题，像读教义手册一样。结果是读到矛盾（同一首诗中同时自义又认罪）、读到困惑（咒诅诗篇中的仇恨与爱的诫命冲突）、读到抵触（赞美像谄媚独裁者）。人的思维偏好命题化，但诗歌的意义在整体意境不在逐行命题。
  - 警告信号：读到一首诗篇时感到矛盾或困惑；试图逐节提取"教义要点"；把对仗的两行当作对立或递进的命题；用系统神学的框架去套诗歌。

### 作者的盲点 / 时代局限

- Lewis 断言"对仗是翻译后仍不失的格律"，但实际上翻译后对仗效果必然受损（不同语言的对仗机制不同），这一说法更像修辞而非事实陈述。
- Lewis 的"业余者"姿态具有双重性：自称业余但展示远超业余的学识（味吉尔、柏拉图、约翰·多恩），这既是谦逊也是论证策略——降低读者防备后施加学识权威。

### 容易混淆的邻近方法论

- `imprecation-three-step`（面对反感文本的情绪处理）——本 skill 是前置的体裁判定，后者是后续的情绪接纳
- `elevated-literature-reading`（被提昇文学的阅读法）——本 skill 处理诗歌体裁的通用规则，后者处理宗教权威文本的特殊阅读姿态
